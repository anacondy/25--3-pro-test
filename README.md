# Visual Hierarchy - Interactive Design Showcase

An interactive glassmorphic design showcase featuring beautiful animations and smooth transitions, exploring fundamental design principles.

![Visual Hierarchy Showcase](https://github.com/user-attachments/assets/b70170b9-d498-4bbd-8b40-864490e86060)

## 🎨 Features

- **Glassmorphic Design**: Modern glass-effect UI with backdrop blur and transparency
- **Interactive Slider**: Navigate through 6 design principle cards using arrow keys or swipe gestures
- **Dynamic Color Themes**: Each slide has its own unique color scheme with smooth transitions
- **Responsive Design**: Optimized for 16:9 and 20:9 aspect ratios (1920x1080, 2560x1080, and more)
- **Smooth Animations**: Hardware-accelerated transitions for buttery smooth performance
- **Touch Support**: Swipe left/right on touch devices to navigate between slides

## 📚 Design Principles Covered

1. **Visual Hierarchy** - Guiding the Eye
2. **Color Theory** - Emotional Impact
3. **Typography** - Voice & Tone
4. **UX Design** - Solving Problems
5. **White Space** - Room to Breathe
6. **Accessibility** - Design for Everyone

## 🎮 How to Use

1. **Keyboard Navigation**: Use the `←` (Left Arrow) and `→` (Right Arrow) keys to navigate between slides
2. **Touch Navigation**: On touch devices, swipe left or right to move between slides
3. **Responsive**: The site automatically adapts to your screen size and aspect ratio

## 🛠️ Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/anacondy/25--3-pro-test.git
   cd 25--3-pro-test
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## ⚡ Performance Optimizations

- Hardware-accelerated CSS animations using `transform` and `will-change`
- Optimized backdrop-filter usage
- Debounced resize event handlers
- Passive event listeners for touch events
- CSS containment for better rendering performance

## 🌟 Key Features

### Glassomorphic Theme
The entire design maintains a consistent glassmorphic aesthetic with:
- Semi-transparent backgrounds
- Backdrop blur effects
- Subtle borders and shadows
- Frosted glass appearance

### Smooth Animations
All transitions use optimized cubic-bezier easing functions:
- Card transitions: `cubic-bezier(0.25, 1, 0.5, 1)`
- Color changes: `cubic-bezier(0.4, 0, 0.2, 1)`
- Floating animations with ease-in-out

### Aspect Ratio Optimization
Special media queries ensure perfect rendering on:
- 16:9 displays (1920x1080, 1600x900, etc.)
- 20:9 ultrawide displays (2560x1080, 3440x1440, etc.)
- Standard displays (1280x720, 1366x768, etc.)
