# Getting Started

Welcome! This guide will help you get started with the Visual Hierarchy Interactive Showcase.

## 🌐 Viewing Online

The easiest way to experience the showcase is to visit the live demo:

**Live URL**: [https://anacondy.github.io/25--3-pro-test/](https://anacondy.github.io/25--3-pro-test/)

## 🖱️ Navigation

### Keyboard Navigation (Desktop)

- **Right Arrow (→)**: Move to the next slide
- **Left Arrow (←)**: Move to the previous slide

### Touch Navigation (Mobile/Tablet)

- **Swipe Left**: Move to the next slide
- **Swipe Right**: Move to the previous slide

## 📱 Device Compatibility

The showcase is optimized for:

- **Desktop**: 1920×1080 (16:9), 2560×1080 (21:9), and similar resolutions
- **Laptop**: 1366×768, 1600×900, and similar resolutions
- **Tablet**: iPad and Android tablets in landscape mode
- **Mobile**: Modern smartphones (though best experienced on larger screens)

## 🎯 What to Explore

The showcase features **6 interactive slides**, each focusing on a core design principle:

1. **Visual Hierarchy** - Learn how to guide the viewer's eye
2. **Color Theory** - Understanding emotional impact of colors
3. **Typography** - The voice and tone of design
4. **UX Design** - Solving user problems effectively
5. **White Space** - The power of breathing room
6. **Accessibility** - Designing for everyone

## 💻 Running Locally

If you want to run the project on your local machine:

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional but recommended)

### Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/anacondy/25--3-pro-test.git
   cd 25--3-pro-test
   ```

2. **Option A: Open directly** (may have limited features):
   - Simply open `index.html` in your browser

3. **Option B: Use a local server** (recommended):
   
   Using Python:
   ```bash
   python3 -m http.server 8000
   ```
   
   Using Node.js:
   ```bash
   npx http-server
   ```
   
   Using PHP:
   ```bash
   php -S localhost:8000
   ```

4. **Open in browser**:
   - Navigate to `http://localhost:8000`

## 🔍 Tips for Best Experience

1. **Use a larger screen** for the best visual experience (1920×1080 or higher)
2. **Enable hardware acceleration** in your browser settings for smoothest animations
3. **Use a modern browser** (Chrome, Firefox, Safari, Edge - latest versions)
4. **Disable browser extensions** that might interfere with animations
5. **View in fullscreen** for immersive experience (F11 on most browsers)

## ❓ Troubleshooting

### Animations are choppy
- Ensure hardware acceleration is enabled in browser settings
- Close other resource-intensive applications
- Try a different browser

### Slides won't navigate
- Make sure you're using arrow keys (not scrolling)
- Try clicking on the page first to ensure it has focus
- Check browser console for JavaScript errors

### Layout looks broken
- Ensure you're using a modern browser
- Try clearing browser cache and refreshing
- Check your screen resolution is supported
