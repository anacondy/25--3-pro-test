## 🎨 About This Project

The Visual Hierarchy Interactive Showcase is a modern web application that demonstrates fundamental design principles through an interactive glassmorphic interface. Each slide in the showcase focuses on a different aspect of design:

- Visual Hierarchy
- Color Theory
- Typography
- UX Design
- White Space
- Accessibility

## 🚀 Quick Start

Visit the live demo at: [https://anacondy.github.io/25--3-pro-test/](https://anacondy.github.io/25--3-pro-test/)

Use arrow keys (← →) or swipe gestures to navigate between slides.

## 💡 Key Features

- **Glassmorphic Design**: Modern frosted glass aesthetic
- **Smooth Animations**: Hardware-accelerated transitions
- **Responsive Layout**: Optimized for 16:9 and 20:9 displays
- **Touch Support**: Swipe navigation for mobile devices
- **Accessibility**: Semantic HTML and keyboard navigation
